Root cause
  NtAllocateVirtualMemory used the contiguous physical allocation pool. Reserving
  an address range therefore occupied that same scarce pool, and committing new
  ordinary virtual memory required a single physical-address hole large enough
  for the whole allocation. Decommit left the reservation blocking that pool.
  A longer session with minigame changes exposed the resulting false exhaustion.

Correction
  Pageable reservations use valid addresses in the remaining Xbox user address
  space, above the bridge's existing direct RAM window and below 7FFF0000.
  Native VirtualAlloc/VirtualFree provide backing on commit/decommit/release.
  Only committed pages consume the shared 64 MiB guest physical-memory budget.
  Physical/system/cache allocations retain their bounded contiguous RAM pool.
  Reservations do not consume that pool or physical commitment. Failed requests
  still return real failure, including commitment beyond the guest memory budget.

  Committed virtual ranges map to their native backing through Memory's bounded
  mapping table. Adjacent spans from the same native reservation join, so native
  bulk reads/copies remain contiguous across successive page commitments.
  Decommit removes the readable mapping and releases backing; recommit restores
  zeroed pages without changing neighboring committed bytes. Query and protection
  metadata retain virtual address high bits, distinct from physical aliases.
  GPU cache invalidation is retained for representable released/decommitted ranges.
  Failure reports now distinguish available physical bytes from address holes.

  F8 captures stream committed pageable bytes to bounded virtual-memory.bin,
  alongside the existing guest-memory.bin. CPU probes restore both and include
  their hashes. This preserves diagnostics when the process heap lies outside
  the direct RAM window. No runtime guest instruction decoding was introduced.

  Native pageable backing has no exposed guest physical page identity. An actual
  MmGetPhysicalAddress request for such backing stops explicitly rather than
  returning a false masked address. The supplied full session has zero calls to
  that export; the game's contiguous GPU allocations retain their physical aliases.
