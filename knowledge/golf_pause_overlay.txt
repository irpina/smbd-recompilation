The earlier solid-sprite correction was incomplete: scene copies, projected

Current implementation

The verified immediate frontend31200..31462 builds the plain XYZ, colour and
UV quad layouts. One hook at313B0 (original bytesA174EF6D00) calls
align_screen_rectangle in src/cpu.cpp before the original packet submission.
This includes folded tail-call bodies and every quad within a batched draw.
There is no overlay caller address, sprite/texture ID or fixed screen size in
the coverage policy. Original assets and caller descriptors stay unchanged.

The helper uses the same projection * model/view matrix that2F790 uploads to
k96..99, plus the current SDK viewport. It recognizes complete viewport quads,
full legacy-canvas rectangles under wider orthographic projections, and depth
masks. Depth masks are identified by their rendering operation: plain XYZ with
blending ZERO + destination ONE and ADD, which preserves all colour/alpha.
This covers subrectangles such as the minimap mask, not only full-screen quads.

Edges are completed on the NV2A1/16 grid with outward1/32 raster coverage.
The conversion inverts signed truncation, so a positive viewport origin gets
the same margin as origin0. A single fixed subtraction does not achieve this.
UVs and optional packed colours follow the resulting raster edges; copied
texels retain their pixel alignment. Nonrectangular, nonplanar, partial UI and
normal/skinning geometry are excluded. Projection, depth and draw order remain
original. Scratch storage is fixed per quad; there is no scan, cache or allocation.

The scene-copy producer omitted the legacy half-pixel screen-origin correction.
The existing NV2A subpixel snapping and raster bias leave its upper/left edges
inside the target. src/recompiler.cpp now corrects that producer's four position
calls (0005B772, 0005B7CB, 0005B823, 0005B882) and four UV calls
(0005B77B, 0005B7D7, 0005B832, 0005B88E). Each original call target/signature
is checked during generation. Low positions subtract 0.5625; high positions
subtract 0.4375. After snapping, the rectangle extends 1/32 pixel beyond each
edge. Matching UV extensions of 1/(32*width) and 1/(32*height), using the
original display dimensions, keep source texels aligned with destination pixels.
The native before/after 804-byte packets differ only in those XY and UV words.
No global geometry offset, clear-colour replacement or blending change is used.
