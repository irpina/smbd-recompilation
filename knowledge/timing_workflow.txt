Research and correction procedure:
1. Group candidates by owning event, handler table and persistent field. Use
   inventory.json and calls.json to find shared producers and consumers.
2. Reuse prior analysis or issue one bounded analyse-set for that family.
   Check the original operand order, units, field width, flags/ABI, resets,
   wrap, pause and lifecycle. Follow both sides of displacement/velocity
   conversions and both producers and consumers of short-lived events.
3. Supply a small valid state to probe-cpu. '-' constructs memory from the
   verified XBE for asset-independent routines. Asset cases require a real
   capture with the researched snapshot hash; missing assets/host services
   are explicit failures, never substitute successful API returns.
   For mixed routines, call-until ENTRY BREAKPOINT LIMIT STACK [ARG...] uses
   the existing AOT diagnostic breakpoint. It stops before a chosen function,
   reports returned=false and the exact breakpoint, and permits state reads.
   A missing breakpoint or other native boundary fails. This proves only the
   executed prefix, never the skipped drawing or a successful host API call.
4. Reproduce before changing the lowering. Compare equal elapsed time across
   60, 75, 120, 144, 165, 240, 360 and 1000 Hz, uneven uncapped intervals,
   and bounded catch-up intervals. A 30-cap check retains 60 Hz scene steps.
   These interval schedules are numeric probes, not monitor/FPS measurements.
5. Check intermediate samples as well as endpoints. Include event expiry,
   clip wrap, state changes and pause; steady-state agreement alone is weak.
   Preserve independently derived rules and recorded 60 Hz bytes. Fix shared
   units/clocks/ownership at their producer instead of multiplying arbitrary
   additions or holding an entire mixed update/draw routine.
6. Rebuild, rerun numeric probes, then run silent hidden gameplay routes with
   isolated settings/saves. Compare event ticks and fresh per-scene motion
   and drawing. Visual acceptance remains the user's manual check.
